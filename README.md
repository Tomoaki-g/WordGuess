# WordGuess

WordGuessは、英単語を使ったコード推理ゲームです。アルファベットを組み合わせて隠された英単語を予想し、文字ごとの判定をヒントに正解を目指します。

現在開発中で、以下の機能を実装予定です。

## 遊び方

1. 3〜6文字の英単語をお題にしてゲームを始めます。
2. 画面上のQWERTY配列のキーボードから文字を選び、英単語を入力します。
3. 予想を確定すると、それぞれの文字に判定が表示されます。
   - **完全一致**：文字と位置がどちらも正しい。
   - **位置違い**：正解に含まれる文字だが、位置が異なる。
   - **一致なし**：その文字に対応する一致がない。
4. 判定を手がかりに予想を繰り返し、隠された英単語を当てます。

## 特徴

- お題と予想の両方に、有効な英単語を使用します。
- A〜Zの26文字をQWERTY配列のキーボードから入力できます。
- 判定は各文字の上に直接表示し、色や装飾で区別します。
- 3〜6文字の単語に対応します。
- ゲームをリスタートして、何度でも挑戦できます。
- 文字の判定や画面の変化を、アニメーションで分かりやすく伝えます。
